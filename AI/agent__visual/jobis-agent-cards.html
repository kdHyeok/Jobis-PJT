src/jobis_ai/graph/builder.py 가 조립하는 10개 노드를 흐름도 한 장과 에이전트 카드 10장으로 정리했다. 모든 노드는 단일 GraphState 를 읽고 부분 갱신 dict 를 돌려준다.

조건부 라우터 — 스스로 판단하지 않음

판단 · 매칭 · 계산은 알고리즘(룰 / DB / 임베딩 / RAG)이 하고, LLM은 입구(읽기)와 출구(말하기)에만 둔다.
판단 계층 노드에 LLM 배지가 새로 생기면 그 자체로 설계 위반이다.
