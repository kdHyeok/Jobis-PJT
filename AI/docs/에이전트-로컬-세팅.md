# 실제 UI에서 진짜 에이전트와 대화하기 — 로컬 세팅 (develop 기준)

> develop 을 받은 팀원이 **가짜 AI(fake-ai) 대신 진짜 멀티에이전트**를 붙여
> 브라우저에서 대화·공고 분석까지 해 보는 가이드다. 루트 `RUN.md` 의 3번(가짜 AI)만
> 이 문서로 바꾸면 되고, 나머지(DB·백엔드)는 `RUN.md` 그대로다.
>
> 에이전트가 어떻게 생겼는지는 `docs/멀티에이전트-구조-설명.md`, 서비스 v2 백엔드에
> 붙이는 법은 `docs/v2bridge.md` 참고.

## 0. 준비물

| 프로그램 | 왜 필요한가 | 확인 |
|---|---|---|
| Java 17 | 백엔드 | `java --version` |
| PostgreSQL 14+ | 백엔드 DB | `RUN.md` §1 |
| **uv** | AI 서버 실행(의존성 자동 설치) | `uv --version` — 없으면 PowerShell: `irm https://astral.sh/uv/install.ps1 \| iex` |
| **Claude Code CLI (로그인 상태)** | 에이전트의 LLM | `claude --version` 후 아무 명령이나 실행해 로그인 확인 |

Node.js 는 **필요 없다** — fake-ai 를 안 띄우기 때문이다. 포트 8000 에는
가짜 AI 와 진짜 에이전트 **둘 중 하나만** 띄운다.

## 1. DB · 백엔드 환경 파일

루트 `RUN.md` §1(롤·DB 생성) → §2(`backend/.env`) 그대로 진행한다.

## 2. AI 환경 파일 — `AI/.env` (git 에 없음, 직접 생성)

`AI` 폴더에 `.env` 파일을 만들고 최소 한 줄을 넣는다:

```dotenv
LLM_PROVIDER=claude_code
```

- `claude_code` 는 **로컬에 로그인된 Claude CLI** 를 쓴다 — API 키가 필요 없다.
- 선택(공고 URL 수집 품질용): `JINA_API_KEY=…` (본문 리더),
  `FIRECRAWL_API_KEY=…` (JS 렌더링 페이지), `TAVILY_API_KEY=…` (최종 보조 추출),
  `CLOVA_API_KEY=…` (이미지 공고)
  (캡쳐 이미지 텍스트화). 없어도 대화·분석은 되고, 일부 사이트의 URL 수집만 약해진다.

## 3. AI 서버 실행 (포트 8000) — fake-ai 자리에 진짜 에이전트

```powershell
cd AI
$env:PYTHONUTF8 = "1"
uv run --with fastapi,uvicorn,websockets uvicorn jobis_ai.webbridge.app:app --host 127.0.0.1 --port 8000
```

- 첫 실행은 uv 가 의존성을 받느라 1~2분 걸린다. `Uvicorn running on http://127.0.0.1:8000` 이 뜨면 준비 완료.
- 확인: 브라우저에서 `http://localhost:8000/health` → `{"status":"ok","engine":"jobis-ai"}`
- 백엔드 없이 에이전트만 먼저 구경하려면 `http://localhost:8000/ui` (개발용 대화 페이지).

## 4. 백엔드 실행 (포트 8080)

```powershell
cd backend
.\gradlew.bat bootRun --args="--spring.profiles.active=local"
```

`Started BackendApplication` 이 뜨면 준비 완료. (백엔드는 AI 서버 주소를 기본값
`localhost:8000` 으로 보므로 추가 설정이 없다.)

## 5. 브라우저에서 대화

```
http://localhost:8080/login.html
```

회원가입 → 로그인 → **AI와 대화**. 이런 걸 해 보면 에이전트 동작이 잘 보인다:

1. **일반 상담** — "백엔드 취업 준비 뭐부터 할까요?" → 진로 대화 담당이 답한다.
2. **공고 URL 붙여넣기** — 사람인·잡코리아 공고 주소만 붙여넣는다(http 없어도 됨).
   → 자동 수집(수십 초) 후 필수/우대 요건이 항목화되어 온다. 수집이 막힌 사이트면
   본문 붙여넣기를 요청한다 — 공고 원문을 복사해 붙여넣으면 된다.
3. **이력서 등록** — 커리어 저장소에 이력서를 넣고 "이 공고에 적합한지 분석해줘"
   → 요건별 충족/미충족과 등급, 준비 로드맵까지 나온다.
4. **이어가기** — 분석 뒤 "자소서 초안 써줘", "면접 질문 뽑아줘"가 같은 맥락에서 이어진다.

첫 응답은 Claude CLI 특성상 **수십 초** 걸릴 수 있다(진행 문구가 흐른다).

## 6. 문제 해결

| 증상 | 원인·조치 |
|---|---|
| 대화하면 "대화 처리 실패(404)" | 8000 에 fake-ai 가 떠 있다 — 끄고 이 문서 §3 의 서버로 교체 |
| `/health` 의 응답이 안 옴 | AI 서버 로그 확인. `.env` 위치가 `AI/.env` 인지 확인 |
| 응답이 "LLM 이 설정되지 않아…" | Claude CLI 로그인 안 됨 — 터미널에서 `claude` 실행해 로그인 |
| 공고 URL 이 일반 대화로 처리됨 | 주소만 한 줄로 붙여넣었는지 확인(문장 속 주소는 대화로 봄) |
| URL 수집 실패 안내가 옴 | 정상 동작(막힌 사이트) — 안내대로 공고 본문을 붙여넣으면 이어진다 |
| 백엔드가 `Connection refused` | PostgreSQL 미기동 또는 `backend/.env` 값 확인 (`RUN.md` §1·2) |

## 부록 — 서비스 v2(Vue 프론트) 스택으로 보려면

v2 프론트/백엔드(`feat/be/jobiss-service-v2`)는 아직 develop 에 없다. 그 브랜치를
체크아웃해 팀 README 대로 띄우되, AI 서버만 이 저장소의 v2 계약 브릿지로 바꾼다:

```powershell
cd AI
uv run --with fastapi,uvicorn uvicorn jobis_ai.v2bridge.app:app --host 127.0.0.1 --port 8000
```

백엔드·프론트 설정은 그대로 두면 된다(기본 `AI_SERVER_URL` 이 8000). 상세: `docs/v2bridge.md`.
