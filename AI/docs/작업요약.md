# 오늘 만든 것, 쉽게 풀어보기 (2026-07-15)



---

## 0. 먼저, 큰 그림

우리가 만드는 **자비스(잡퀘스트)** 는 취업 준비생을 돕는 서비스입니다.
사용자가 **가고 싶은 채용공고**와 **자기 이력서**를 넣으면, AI가
"당신은 이 공고에 뭐가 충분하고 뭐가 부족한지, 그 부족함을 어떻게 채우면 되는지"를 알려줍니다.

이 서비스는 세 팀이 나눠 만듭니다 — 화면(프론트엔드), 서버(백엔드), 그리고 **AI 두뇌**.
제가 맡은 건 이 **AI 두뇌**이고, 오늘은 이 두뇌를 실제로 "생각하게" 만들었습니다.

> **비유** — 한 명의 만능 AI가 다 하는 게 아니라, 서로 다른 일을 맡은 **AI 담당자 여러 명이 한 팀**으로
> 일하게 만들었습니다. 취업 컨설팅 회사에 "공고 분석가", "이력서 정리 담당", "진단 담당"이 따로 있고,
> 서류가 담당자를 차례로 거쳐 완성되는 것과 같아요.

## 1. 한눈에 보기 — 서류가 담당자들을 차례로 거칩니다

사용자 요청이 들어오면 아래 순서로 AI 담당자가 한 명씩 일을 이어받습니다.
오늘 이 **6단계 전부**가 실제로 작동하게 됐어요.

| 순서 | 담당자 | 하는 일 |
|---|---|---|
| 1 | 공고 분석가 | 채용공고를 읽어 "필수 / 우대 / 필요 기술"로 정리 |
| 2 | 이력서 정리가 | 이력서(워드 파일)를 읽어 경력·프로젝트·기술·근거로 구조화 |
| 3 | 격차 진단가 | 공고가 원하는 것 ↔ 내가 가진 것 비교 → 강점·부족 판정 |
| 4 | 로드맵 설계가 | 부족한 점을 기간·시간 안에서 "주차별 계획"으로 변환 |
| 5 | 대안 제시가 *(선택)* | 바로 가기 어려우면 "돌아가는 길"(비슷한 직무 등) 제안 |
| 6 | 검수관 | 거짓·과장이 없는지 마지막 점검 → 문제 있으면 다시 시키기 |

## 2. AI 담당자 6명이 하는 일

전에는 이 담당자들이 **가짜 예시 답변만 돌려주는 껍데기**였어요.
오늘 **진짜로 생각해서 답하도록** 하나씩 바꿨습니다.

**1) 공고 분석가** — 채용공고 글을 읽고 "꼭 필요한 조건, 있으면 좋은 조건, 요구 기술"로 나눠 정리합니다.
링크·텍스트·파일 어떤 형태로 넣어도 읽어냅니다.
*비유: 긴 공고를 형광펜으로 요점만 표시해 표로 만들어 주는 사람.*

**2) 이력서 정리가** — 워드(.docx) 이력서를 읽어 학력·경력·프로젝트·기술·자격증으로 구조화하고,
"이 사람이 잘한다"는 **근거 문장**까지 뽑아 둡니다.
*비유: 두서없는 이력서를 깔끔한 한 장 요약으로 다시 써 주는 사람.*

**3) 격차 진단가** — 공고 조건마다 "충족 / 부분 충족 / 부족"을 판정하고 강점·부족을 정리합니다.
"합격/불합격" 같은 **단정은 하지 않도록** 막아뒀어요.
*비유: 체크리스트를 들고 "이건 되고 저건 아직"이라 짚어 주는 코치.*

**4) 로드맵 설계가** — 부족한 점을 **"몇 주 동안, 주당 몇 시간"** 안에서 실행 가능한 주차별 계획으로 바꿉니다.
각 계획엔 "이러면 끝났다"는 확인 기준도 붙습니다.
*비유: 목표를 달력에 촘촘히 나눠 적어 주는 학습 플래너.*

**5) 대안 제시가** — 목표에 바로 가기 어려우면 "돌아가는 길"(비슷한 직무, 신입/인턴 자리 등)을 제안합니다.
아직 실제 공고 자료가 연결 전이라 **없는 회사를 지어내지 않고** 방향만 제시해요.
*비유: "정문이 막히면 옆문으로"를 알려 주는 진로 상담사.*

**6) 검수관** — 최종 답에 거짓·과장·근거 없는 말이 없는지 점검합니다. 특히 AI가 **없는 근거를 지어내면**
잡아내고, 심하면 진단가에게 다시 시킵니다.
*비유: 나가기 전 서류를 마지막으로 검토하는 꼼꼼한 팀장.*

## 3. 보이지 않는 뒷단 — 공통 "도구"

담당자 6명이 매번 처음부터 하지 않도록 공통 도구를 따로 만들었습니다.
나중에 **부품처럼 갈아 끼우기 쉽게** 설계한 게 핵심이에요.

- **🔑 설정 보관함** — 개인 키·모델 이름 같은 "사람마다 다른 값"을 코드 밖에 뒀습니다. 팀원은 자기 값만 넣으면 동작.
- **🧠 AI 모델 연결구** — 실제 생각하는 AI 모델에 연결하는 부분. AI 회사를 바꿔도 담당자 코드는 그대로.
- **📄 문서 읽기 도구** — 워드·PDF·링크에서 글자를 뽑아냅니다. 못 읽어도 멈추지 않고 "경고"만 남기고 넘어감.
- **📋 정해진 양식 도구** — AI의 답을 항상 **같은 표 형식**으로 받아냅니다. 그래야 다음 담당자가 바로 이어받아요.

## 4. 'RAG'는 뭐고, 왜 "자리만" 만들었나?

**RAG** 는 쉽게 말해 AI가 **외부 자료를 찾아보고 참고하는 능력**입니다.
예를 들어 "이 회사는 어떤 인재를 원하나?"를 알려면 회사 정보를 검색해 와야 하죠.

그런데 RAG는 **다른 팀원이 전담**하고 있습니다. 그래서 저는 RAG를 직접 만들지 않고,
나중에 그 결과가 **쏙 꽂힐 "자리"(연결 규격)** 만 깔끔하게 만들어 뒀어요.
지금은 그 자리가 비어 있어도 서비스는 멀쩡히 돌아갑니다.

> **비유** — 집에 **콘센트(규격)를 미리 설치**한 것과 같아요. 아직 냉장고(RAG)는 안 왔지만,
> 나중에 사 오면 플러그만 꽂으면 바로 작동합니다. 벽을 다시 뜯을 필요가 없죠.

또한 그 팀원이 **무엇을 준비해야 하는지**(어떤 규격으로 만들지, 어떤 데이터가 필요한지)를 정리한
**안내 문서**도 함께 만들어 전달했습니다.

## 5. 믿을 수 있게 만들기 — 테스트와 우리가 잡은 버그

기능을 만드는 것만큼 중요한 게 "고장 안 나는지" 계속 확인하는 일입니다.
그래서 **자동 점검(테스트)** 을 붙였어요. 사람이 매번 확인하지 않아도 버튼 한 번이면 전부 검사됩니다.

**🔎 발견** — 검수관이 "다시 해!"라고 되돌려 보내는 기능이 있는데, 확인해 보니
**실제로는 한 번도 되돌리지 못하고 그냥 통과**되고 있었어요(조건을 이중으로 검사하는 실수).
겉으론 멀쩡해 보여서 나중에 발견됐다면 훨씬 골치 아팠을 문제입니다.

**✅ 수정** — 원인을 고쳐 "되돌리기"가 정상 작동하게 만들고(무한 반복도 안 하도록),
같은 문제가 다시 생기면 즉시 알 수 있는 자동 점검을 추가했습니다.
덤으로 점검 속도도 **76초 → 1초**로 줄여 앞으로 훨씬 자주 돌릴 수 있게 됐어요.

## 6. 오늘의 하이라이트 — AI에게 "성적표"를 만들고, 점수를 올렸어요

AI가 얼마나 잘하는지 **느낌이 아니라 숫자로** 재는 도구를 만들었습니다. 채점 항목은:

- 공고를 정확히 정리했나
- 근거를 지어내지 않았나
- 금지 표현을 안 썼나
- 계획이 주어진 시간을 안 넘겼나

그리고 곧바로 한 항목을 개선했습니다. 성적표를 돌려 보니 계획 담당가가
**촉박한 일정에서 시간을 초과하는 계획**을 세우더군요. 그래서 "예산을 넘으면 덜 중요한 항목부터
빼서 시간에 맞추도록" 고치고, 같은 성적표로 다시 쟀습니다.

```
계획 준수율   0.5  →  1.0   (개선 전 → 개선 후)
```

두 예시 중 하나가 시간 초과였는데 수정 후 **둘 다 시간 안에** 들어왔고, 다른 점수는 그대로였습니다(부작용 없음).

> **왜 중요하냐면** — "문제를 숫자로 발견 → 고침 → 다시 재서 좋아진 걸 숫자로 증명" 이 과정 자체가
> 발표·평가에서 보여줄 수 있는 확실한 성과예요. 화면만 봐선 안 보이는 실력이죠.

## 용어 사전 — 이 단어만 알면 충분해요

| 용어 | 쉬운 뜻 |
|---|---|
| **AI 모델 (LLM)** | 사람 말을 이해하고 글로 답하는 AI. ChatGPT의 두뇌 같은 것. |
| **담당자 / 노드 (Node)** | 한 가지 일을 맡은 AI 일꾼. "공고 분석가" 같은 것. |
| **구조화 (파싱)** | 줄글 정보를 표·항목처럼 정리하는 것. |
| **근거 (Evidence)** | "이 사람이 잘한다"를 뒷받침하는 이력서 속 실제 문장. |
| **환각 (Hallucination)** | AI가 없는 사실을 그럴듯하게 지어내는 현상. 검수관이 잡음. |
| **RAG** | AI가 외부 자료를 검색해 참고하는 능력. |
| **테스트** | 기능이 고장 안 났는지 자동으로 확인하는 검사. |
| **커밋 / 푸시** | 커밋 = 작업 저장, 푸시 = 팀 저장소에 올리기. |
| **평가 지표 (성적표)** | AI가 얼마나 잘했는지 숫자로 매기는 채점표. |
