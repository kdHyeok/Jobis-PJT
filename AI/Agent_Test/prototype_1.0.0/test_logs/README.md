# test_logs — 테스트 실행 기록

> 테스트를 **돌릴 때마다** 여기에 남긴다: **테스트일 · 대상 프로그램 · 실행 명령 · 커밋 · 결과 · 피드백/후기.**
> 구분: `tests/` = 테스트 **코드** / `test_logs/` = 테스트 **실행 결과·후기 이력**.

## 형식 (파일명: `YYYY-MM-DD_<대상>.md`)
```
- 테스트일 / 대상 프로그램(제목·목적) / 실행 명령 / 커밋
## 결과       — PASS·FAIL 수치, 주요 지표
## 실행 로그 (raw) — **실제 출력 그대로**(증거·재현용). 팁: `python -m tests.eval > log.txt`로 캡처
## 피드백·후기 — 관찰·이상·개선점(→ 반영 시 커밋 링크)
```
