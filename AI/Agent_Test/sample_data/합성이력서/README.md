# 합성 이력서 (테스트 픽스처) — 1.0.1 강건화용

> 이서현(프론트) 이력서 **양식만 참고**해 만든 합성 데이터. 실제 인물 아님.
> 목적: **"여러 텍스트 이력서·다양 케이스에도 라우팅/갭분석이 잘 도나"**(1.0.1)를 테스트.

## 설계 원칙 (중요)
- **프로필축 ≠ 시나리오축.** S1~S6(추천/정리/갭/검색/일상/거절)은 **쿼리로** 갈린다. 이력서는 시나리오가 아니라 **gap 상/중/하 + 매칭 풍부/희소**를 커버한다.
- "노림 난이도"는 **설계 의도지 보장이 아님** — mock 검색·LLM 비결정성 때문. 실제로 의도대로 나오는지는 `tests/eval.py`로 관찰하고, **어긋나면 그게 1.0.1 강건화 대상.**
- 이미지공고(E2) 테스트는 공고셋의 `need_ocr=O`(310건)로 별도로 되므로 이력서 불필요.
