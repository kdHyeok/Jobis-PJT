## 확인된 성질

- 모델은 회사별 작은 과제를 여러 개 만들지 않고 공고 하나당 하나의 목표 프로젝트를 만든다.
- 모델이 프로젝트에 넣을 수 있는 역량 ID는 정규화 결과가 제공한 필수·우대 ID로 제한된다.
- 필수 역량은 `UNLOCKS_PROJECT`, 우대 역량은 비차단 `BONUS_SUPPORTS_PROJECT` 관계가 된다.
- 승인된 역량 그래프만 학습 선행관계를 제공하며 모델은 임의 선행관계를 만들지 않는다.
- 기존 canonical node와 진행 상태는 재사용되며 신규 공고 때문에 초기화되지 않는다.
- 회사 기회에는 직무군·세부 직무·선택 경력 트랙·최소 경력 개월이 남아, 하나의 지도에서
  신입 회사와 2년·3년·5년 경력 회사를 단계별로 배치할 수 있다.
- 결과는 항상 `DRAFT`이며 AI 서버가 공개 로드맵을 직접 적용하지 않는다.
