- 평가일: 2026-08-04
- 공급자: 로컬 Claude Code CLI 2.1.220

- 인터프리터: `posting-interpreter-3.0.0`
- 실행 스크립트: `ai-v3/scripts/eval_phase3_live.py`

## 목적

단위 테스트의 scripted provider는 계약·컴파일러·근거 검증을 확인하지만 모델의 실제 의미 해석
정확도를 증명하지 않는다. 이 평가는 사용자가 실제로 겪은 직무·경력·요건 회귀를 모델에 직접
입력해 최종 `StructuredPosting`을 검사한다.

## 평가 중 발견해 고친 계약 결함

### 전체 공고 제목이 없는 입력

첫 EXP-003 실행에서 모델이 여러 포지션을 합친 제목을 만들었고 exact evidence 검증이 차단했다.
재시도로 억지 근거를 만들지 않고 `postingTitle=null`을 허용하도록 계약과 프롬프트를 수정했다.
수정 후 동일 사례는 PASS였다.

### 담당 업무의 원문과 정리 문장 혼합

첫 ROLE-004 실행에서 게임 서버 직무 분류는 맞았지만 모델이 담당 업무를 요약해 exact evidence
검증이 차단했다. `Responsibility`도 requirement처럼 `sourceText`와 `atomicText`로 분리했다.
수정 후 동일 사례는 PASS였다.

두 실패 모두 검증기를 느슨하게 풀지 않고 데이터 모델이 부족했던 지점을 보완했다.
