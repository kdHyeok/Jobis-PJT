# 배포 전 AI 기능 스모크 시나리오

## 목적

배포 전에 실제 `8088` 경로와 외부 AI·수집기를 사용해 다음 계약을 한 번에 확인한다.

1. 커리어 원문이 기술·프로젝트·경력 등 서로 다른 커리어 조각으로 분해되고 확정되는가.
2. 일반 URL과 JavaScript 렌더링 URL이 채용공고 본문 품질 게이트를 통과하는가.
3. 이미지 채용공고에서 회사·직무·담당업무·필수·우대 요건을 읽는가.
4. 검증된 공고와 확정 커리어 자료로 갭 분석을 완주하는가.
5. 대안 공고 추천이 오류 없이 실행되는가.
6. 로드맵 초안에 `CAPABILITY`, `TARGET_PROJECT` 노드와 하나 이상의 관계가 생성되는가.
7. 같은 시간대의 AI·백엔드 로그에 처리되지 않은 예외나 계약 오류가 없는가.

## 채팅창 수동 입력 순서

먼저 커리어 저장소에 이력서를 등록하고 제안된 조각을 확정한다. 이어서 새 공고 분석 화면에서 URL 또는 이미지를 등록한 뒤 아래 문장을 순서대로 입력한다.

1. `커리어 저장소에 등록한 자료를 기준으로 기술·프로젝트·경력 조각이 어떻게 나뉘었는지 요약해줘.`
2. `이 채용공고를 읽고 회사·직무·담당업무·필수요건·우대사항을 정리해줘: https://www.jobkorea.co.kr/Recruit/GI_Read/49686653`
3. `이 자바스크립트 렌더링 채용공고도 실제 직무 원문을 끝까지 읽고 정리해줘: https://hanwhaaerospace-recruit.com/jdebook/#2@01-02@new`
4. 이미지 첨부 후: `방금 이미지에서 읽은 채용공고의 회사·직무·담당업무·필수요건·우대사항을 확인해줘.`
5. `선택한 공고와 확정된 커리어 자료를 비교해서 보유 근거와 부족 역량을 구분한 갭 분석을 해줘.`
6. `이 공고가 맞지 않을 때 지원할 수 있는 대안 공고를 최대 5개 추천해줘. 회사명·직무·매칭 근거·URL을 포함해줘.`
7. `이 공고의 부족 역량을 기준으로 회사 맞춤 프로젝트와 준비 로드맵을 설명해줘. 공고·역량·프로젝트·지원 기회의 연결 관계도 포함해줘.`

## 자동 실행

루트 PowerShell에서 실행한다.

```powershell
.\scripts\run-predeploy-ai-feature-smoke.ps1
```

회원가입 제한에 걸리지 않도록 별도의 테스트 계정을 재사용할 수도 있다. 두 값은 함께 전달해야 하며,
재사용 계정은 스크립트가 삭제하지 않는다.

```powershell
.\scripts\run-predeploy-ai-feature-smoke.ps1 `
  -Email "predeploy@example.com" `
  -Password "<TEST_ACCOUNT_PASSWORD>"
```

외부 공고가 만료되었으면 실행 전에 URL을 교체할 수 있다.

```powershell
$env:E2E_STANDARD_POSTING_URL = "https://접근가능한-일반-채용공고"
$env:E2E_JS_POSTING_URL = "https://접근가능한-SPA-채용공고"
.\scripts\run-predeploy-ai-feature-smoke.ps1
```

테스트는 임시 계정을 만들고 성공 시 삭제 예약한다. 실패 계정을 브라우저에서 조사해야 하면 `-KeepAccount`를 사용한다. 결과와 해당 시간대 서비스 로그는 `artifacts/predeploy-ai-smoke/<시각>/`에 남는다.

## 합격 기준

- 커리어 조각 4개 이상, 종류 3개 이상이며 `SKILL`과 `PROJECT` 또는 `EXPERIENCE`가 포함된다.
- 일반 URL·동적 URL·이미지 모두 공고 신호가 있는 200자 이상의 원문을 반환한다.
- 이미지 OCR이 Java, Spring, PostgreSQL, Docker 중 두 개 이상을 보존한다.
- 분석 잡이 `UNIFIED/SUCCEEDED`이고 필수 요건·fit·roadmap proposal이 비어 있지 않다.
- 로드맵 미리보기에 노드와 관계가 존재하고 역량·목표 프로젝트 노드가 모두 있다.
- Playwright가 성공하고 같은 구간 AI·백엔드 로그에 치명 패턴이 없다.

대안 공고 수는 외부 검색 결과와 시점에 따라 0일 수 있으므로 API와 채팅 실행 성공을 계약으로 보고, 추천 개수는 결과에 별도로 기록한다.
