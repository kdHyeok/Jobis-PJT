죄송하지만 Jenkins를 명시적으로 다루는 대구 DevOps 엔지니어 채용 공고는 없습니다. 가장 가까운 대안들을 제시합니다.

1. 주식회사인사이트노바 - [개발] 벡엔드 및 API 개발자 (7년+ / 대구 동구 / Kubernetes, Docker, Redis, Java, NCP)
   → DevOps 관련 기술(Kubernetes, Docker)을 다루지만 Jenkins는 없습니다.

2. (주)데이타뱅크 - (대구) DB 엔지니어 모집 (1년+ / 대구 수성구 / Linux)
   → 기반 기술(Linux)은 있지만 DevOps 기술이 제한적입니다.

3. (주)다온정보 - 시스템/네트워크/보안 신입 엔지니어 채용 (경력무관 / 대구 달성군)
   → 신입 가능하지만 구체적인 기술 명시가 없습니다.

Jenkins 경험을 요구하는 공고를 찾기 어려우므로, 개별 문의를 통해 관련 경험 활용 가능성을 확인하는 것이 좋겠습니다.
