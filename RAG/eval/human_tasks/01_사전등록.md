## 1. 판정 루브릭 (사람 채점 · LLM judge 공용)

질의와 공고 하나를 비교해 셋 중 하나로 판정한다.

| 라벨 | 기준 |
|---|---|
| **Correct** | 직무·핵심 기술이 부합하고, **하드조건(지역·연차) 위반이 없다** |
| **Ambiguous** | 직무는 부합하나 조건 1개가 미상·경계이거나, 본문을 읽어도 판단이 애매하다 |
| **Incorrect** | 직무가 불일치하거나, 조건을 명백히 위반한다 |

세부 규칙:
- **연차 방향**: 공고 요구 최소연차 ≤ 지원자 연차면 위반 아님. 공고가 "경력무관/미상"이면 위반 아님. 공고 요구가 지원자보다 높으면(예: 3년차 질의 ↔ 5년 이상 공고) **Incorrect**
- **지역**: 공고 근무지가 질의 지역과 겹치면 부합. 공고 지역 미상이면 Ambiguous 사유
- **기술**: 질의의 핵심 기술이 공고의 요구/우대/스택 어디에든 실질적으로 등장하면 부합. 유사 기술 대체(예: 질의 Vue ↔ 공고 React만)는 부합 아님
- **직군**: 질의가 명시한 직군(백엔드/프론트/데브옵스 등)과 공고 직무가 다르면, 기술이 겹쳐도 **Incorrect** (예: "백엔드" 질의에 풀스택 공고 → 백엔드 업무가 명시돼 있으면 Correct 가능, 프론트 전담이면 Incorrect)
- 판단 곤란하면 **Ambiguous로 (안전 쪽)**

## 2. 컴포넌트 유지/제거 결정 규칙

측정 지표: 정규화 nDCG@3, 비교는 쌍대 부트스트랩 95% CI.

| 결정 | 비교 | 규칙 |
|---|---|---|
| CE 리랭커 | rrf vs rrf_ce | CI가 0을 걸치면(유의차 없음) **제거** — 지연·GPU 비용만 남으므로. 유의하게 나쁘면 즉시 제거 |
| BM25 축 | dense vs rrf | rrf가 유의하게 낫지 않으면 BM25 축 제거 |
| 하드필터(지역·연차) | rrf vs rrf_nofilter | 필터가 유의한 이득이 없으면 랭킹 주장에서 제외(UX 요구사항으로만 유지) |
| 완화 로직 | rrf vs rrf_relax | 완화 발동 질의에서 nDCG를 깎으면 제거·단순화 |
| role_category 필터 | role_on vs role_off (adapter 시나리오) | 이득 있으면 복원+오분류 개선, 없으면 코드 삭제+계약 문서 수정 |
| 쿼리 파서 | rrf vs rrf_rawtext | 파서 기여 없으면 지역어휘·연차 룰 단순화 |

## 3. 상수 K · 융합 방식 선택 규칙

- 스윕 대상: RRF_K {10,20,40,60,90} / CANDIDATE_K {10~50} / RERANK_TOP_N {5~30} / min_results {3,5,8} / 융합 alpha {0.3,0.5,0.7} × 정규화(min-max, z-score)
- **피크가 아니라 고원(plateau)에서 선택** — 곡선이 평평해지는 구간의 값
- 융합 방식: 가중합이 RRF 대비 **유의차 없으면 단순한 쪽(RRF) 유지**
- 선택된 값은 홀드아웃 개봉 시 재확인. dev와 방향이 어긋나면 과적합 판정 → 기본값 회귀

## 4. 게이트 (하나라도 FAIL이면 리포트 미생성)

1. 판정 커버리지 100% (미판정 0)
2. random 베이스라인 포함
3. **judge 신뢰성**: (a) 기존 앵커 120쌍 재판정 κ ≥ 0.60, (b) **난이도 축 신규 15쌍 중 12쌍 이상 일치**. 11 이하 → 10쌍 추가 채점 후 재판정, 그래도 미달이면 난이도 축 결론 전체에 `conclusive: false`
4. 자기일관성(기존 recheck 20쌍) κ가 사람-LLM κ보다 낮으면 게이트 3 해석 무효 표기
5. 보고 축 n ≥ 7, arm 비교에 쌍대 CI 필수

## 5. 검증 범위 명시 (리포트 영구 표기)

- 지역/구어체 축은 사람 검증 생략 (기존 앵커가 미커버) — 해당 축 절대 수치는 참고용
- 판정자: Claude (claude CLI), 단일 모델·단일 프롬프트, 버전 박제
- 기존 앵커 120쌍은 질의 분포가 달라(직군형) **대리 검증**임을 명시
- 코퍼스 1,189건 규모·자체 제작 질의의 한계는 기존 PLAN §7 그대로 승계
