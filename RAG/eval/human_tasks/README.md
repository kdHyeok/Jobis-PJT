# 사람 작업 패키지 — RAG 성능 테스트 사전 준비

> 이 폴더의 작업만 끝내면 나머지는 전부 기계가 합니다.
> **총 예상 시간: 35~45분** (+ 나중에 10분 1회)

## 작업 순서

| # | 파일 | 할 일 | 시간 |
|---|---|---|---|
| 1 | [01_사전등록.md](01_사전등록.md) | 판정 루브릭·결정 규칙을 읽고 맨 아래 승인란 체크. **측정 후에는 못 바꾸는 약속**이므로 동의 안 되는 규칙은 지금 수정 요청 | ~10분 |
| 2 | [02_빈라벨_2건.md](02_빈라벨_2건.md) | 기존 앵커(session_easy.csv)에서 비어 있던 라벨 2건을 루브릭 기준으로 기입 | ~5분 |
| 3 | [03_기대파싱값_검수.csv](03_기대파싱값_검수.csv) | 65질의의 기대 파싱값 **초안이 미리 채워져 있음** — 훑어보고 `검수결과` 열에 OK 또는 수정값 기입. ⚠️ 질의 문장만 보고 "의미상 무엇을 원하나"로 판단할 것 (파서 코드 참조 금지 — 순환 채점 방지) | ~20~30분 |
| 4 | (나중) 난이도 축 15쌍 채점 시트 | **지금은 없음.** 풀 구축 + LLM 판정(P2)이 끝나야 표본을 뽑을 수 있어서, 그때 `04_난이도앵커_15쌍.csv`로 자동 생성됨. 규칙: 12/15 이상 일치 → PASS, 11 이하 → 10쌍 추가 | ~10분 (1회) |

## 완료 후

1~3 완료본을 알려주시면 (파일 그대로 저장하고 "완료"라고만 해도 됨):
- 기계가 풀 구축 → LLM 판정(claude CLI, 사람이 실행 명령 1회 시작) → 4번 시트 생성
- 4번 채점(10분) 후 → 게이트 → 측정 → 결정문 포함 리포트

## 참고

- 기존 앵커 120쌍(session_easy/ambiguous/recheck)은 재활용 확정 — 추가 작업 없음
