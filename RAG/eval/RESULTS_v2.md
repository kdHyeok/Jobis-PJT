# RAG 검색 성능 평가 v2 — 최종 결과 (2026-08-04)

> 사전등록: `eval/human_tasks/01_사전등록.md` (측정 전 확정, 측정 후 무변경)
> 정본 데이터: `eval/report_v2.json` (질의별 전체 수치), `eval/pool_v2.json` (풀 원자·스냅샷)

## 1. 테스트 설계 요약

- **풀 원자**: 축(dense/BM25) × 필터구성 3종(전체필터/지역완화/무필터) × 깊이 50 + random 30.
  모든 arm(RRF/CE/가중합/K값 스윕)은 판정 캐시 위에서 오프라인 재조합 — 재검색·재판정 불필요.
- **질의**: 65개를 축 층화 + 결정적 해시로 dev 30 / holdout 35 분할. holdout은 봉인(미개봉).
- **판정자**: claude CLI(비대화 -p) + 루브릭 프롬프트 v4 (`eval/judge.py` PROMPT_V4).
  - 캘리브레이션 이력(본판정 전 완료): v1 κ=0.450(Ambiguous 과용) → v2 0.454(과엄격)
    → v3 0.499 → **v4 0.620 = 게이트 3a PASS** (사람 앵커 120쌍, 이진 strict)
  - judge 자기일관성 κ=0.963 (같은 입력 재판정) — 사람 자기일관성(0.733)보다 높음
    → 동일 판정자 하의 arm 상대비교는 신뢰 가능, 절대수치는 앵커 정렬도(0.62) 한도 내 해석
- **판정 규모**: 5,045쌍, 커버리지 100%. 판정 분포 Incorrect 2,787 / Correct 1,605 / Ambiguous 653.
- **스냅샷**: postings 6,116 (해시 edf0e54b), BGE-M3 임베딩, bge-reranker-v2-m3(cuda).
- **파서 검증**: 사람 검수 기대파싱값 대비 65질의 전부 일치 (불일치 0).

## 4. 개선점 (우선순위)

1. **[P1] 지역 필터 경직성** — 최대 손실원(28건).
   - 완화가 "결과 개수"만 보고 발동: q44(대구)·q48(경남)은 관련 없는 공고로 5개가 차서
     완화 미발동 → 0.0점 (무필터면 0.41~0.54). → 완화 트리거에 품질 신호(상위 dense/CE
     점수 문턱) 추가, 또는 희소 지역에서 region을 소프트 부스트로 강등.
   - 구어체 지명(강남·판교 등) 매핑 과협소: q19~23에서 13건 손실. → 지역 계층 소프트
     매칭(시군구 → 시도 2차 계층).
2. **[P2] RERANK_TOP_N 15→30** — 스윕상 +0.011, 저비용 즉시 적용 가능.
3. **[P3] BM25 축 제거 실험** — 기여 비유의. 제거 시 인메모리 인덱스 재구축·재기동 갱신
   문제 소멸. 지역·제약 축 기여(+0.06~0.14)가 있어 홀드아웃 검증 후 확정.
4. **[P4] 적재 메타데이터 보강** — regions 공백 3건, exp 공백발 침입 1건. 본문에서
   지역·연차 추출 보강 시 recall·precision 동시 개선.
5. **[P5] CE 대표 청크 개선** — ce_demoted 3건(q26: 1.0→0.47). max_length 384 절단이
   유력 원인. 순이득(+0.106)이라 유지하되 대표 청크 선정 개선 여지.
6. **[P6] judge 난이도 축 보강(다음 회차)** — 함정 질의(부정 신호) 규칙 추가 후
   재캘리브레이션해야 난이도 축 절대수치 신뢰 가능.
7. **[P7] 홀드아웃 개봉** — P1~P3 적용 후 `python -m eval.pool_v2 --holdout`으로 1회
   검증 (dev 과적합 확인). 사전등록상 마지막에 1회만.

## 5. 검증 범위 (사전등록 §5 승계)

- 앵커 120쌍은 직군형(SA) 질의라 골든셋 대비 **대리 검증**. 지역/구어체 축 절대수치는 참고용.
- 판정자 단일(claude CLI + PROMPT_V4), 버전 박제. 프롬프트 캘리브레이션은 게이트용
  앵커셋 자체에서 수행됨(가용 라벨이 그것뿐) — 동일 judge가 모든 arm을 채점하므로
  상대비교는 이 한계와 무관.
- 난이도 축 결론 `conclusive: false` (게이트 3b 6/14 — 수학적으로 추가 10쌍으로도 회복 불가).
- 생성(답변) 트랙은 GMS 크레딧 확보 시 별도 진행.

## 6. 재현 방법

```bash
cd RAG
python -m eval.precal              # 판정자 앵커 게이트 (프롬프트 변경 시)
python -m eval.pool_v2             # 풀 원자 구축 (dev 30)
python -m eval.judge_v2            # 본판정 (재개형, 캐시 judgments_v2.json)
python -m eval.difficulty_check --make && (사람 채점) && python -m eval.difficulty_check --score
python -m eval.measure_v2          # 게이트 + 측정 + report_v2.json
python -m eval.pool_v2 --holdout   # 홀드아웃 개봉 (스윕 확정 후 1회만)
```
