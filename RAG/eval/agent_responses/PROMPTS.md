모다플이 해결하고자 하는 것
모빌리티 산업에는 자동차, 주행, 배터리, 환경, 시설 등 다양한 데이터가 존재하지만 이 데이터들은 서로 분절된 형태로 관리되고 활용됩니다. 이로 인해 기업들은 데이터를 충분히 활용하지 못하고, 새로운 수익모델이나 고객경험 확장에도 한계를 겪고 있습니다. 모다플은 이렇게 흩어진 모빌리티 데이터를 하나의 구조로 연결해 실제 비즈니스 가치로 전환하는 문제를 풀고 있습니다.
문제를 해결하는 방법
모다플은 자동차·주행·배터리·환경·시설 데이터를 단일 아키텍처에서 통합·처리하는 데이터 엔진 기업입니다. 수집된 데이터를 연결하고 분석해 모빌리티 산업의 기업들이 새로운 수익모델을 만들고 고객경험을 확장할 수 있도록 돕습니다. 나아가 데이터 수집부터 처리, 분석, 활용까지 전 과정을 아우르는 E2E AI 시스템을 구축해 데이터를 단순히 보여주는 수준을 넘어 실제 비즈니스 가치로 전환하는 데이터 엔진을 만듭니다.
모다플에 합류해야 하는 이유
산업별 선도 기업들과의 협업 프로젝트를 통해 실제 현장에서 사용되는 E2E AI 시스템을 만들어볼 수 있습니다. IoT, 임베디드, 앱, 웹, AI 등 다양한 영역이 연결된 복합적인 기술 문제를 해결하며 빠르게 성장할 수 있습니다. 데이터 수집부터 모델 적용, 서비스 반영까지 전 과정을 주도적으로 경험할 수 있는 환경입니다.
모다플이 찾고있는 `머신러닝 엔지니어`는?
모다플의 머신러닝 엔지니어는 차량/배터리/IoT 센서 등 실제 Physical environment에서 수집되는 대규모 시계열 데이터를 기반으로 현실의 문제를 정의하고 이를 해결할 최적의 머신러닝 모델을 개발하는 역할을 맡습니다. 자동차·주행·배터리·환경·시설 등 다양한 데이터를 활용해 예측, 이상탐지, 상태추정, 이벤트 감지 모델을 설계부터 학습, 검증까지 주도합니다. 나아가 개발된 모델이 실제 서비스 기능과 의사결정에 핵심적인 역할을 하도록 지속해서 고도화하며 배포 이후에도 안정적으로 동작할 수 있도록 성능과 품질을 꼼꼼하게 관리합니다.
